# 복지시험 학습 코치 — 독립형 v2

사회복지사 1급과 2027 지방직 9급 사회복지직을 구분하는 정적 학습 PWA.
외부 iframe, Manus 서버, CDN, AI API 없이 HTML/CSS/JavaScript와 내장 문제만으로 실행됩니다.

실행: https://jinyeong-leesz.github.io/welfare-exam-ai-coach/

## 실제 구현 기능
- 사회복지사 1급 8영역, 지방직 9급 국어·영어·사회복지학개론·행정법총론 및 별도 한국사능력검정 보충.
- 과목별·무작위 문제풀이, 채점, 문항별 고정 해설, 학습 결과.
- 오답노트, 개별 메모, 1·3·7일 복습, 오늘/누적/과목별 정답률, 최근 7일·연속 학습.
- 학습 기록 JSON 백업·검증 후 복원. 기록은 이 기기의 브라우저에 저장되며 클라우드 동기화는 하지 않습니다.
- 앱과 전체 내장 문제·해설을 사전 캐시. HTTPS에서 첫 접속 및 캐시 완료 후 오프라인 사용.
- 모바일 반응형 화면, PWA 설치 안내, 192/512 PNG 아이콘과 manifest.

## 문제 출처 — 반드시 구분
현재 **창작 연습 39문항 / 실제 기출 검증본 0문항**입니다. 각 영역별 기초 3문항이며 실전 전 범위 문제은행이 아닙니다.
창작 문제를 실제 기출, 기출 복원, 공식 모의고사로 표시하지 않습니다. AI API는 없으며 고정 해설을 실시간 AI 답변으로 표시하지 않습니다.
`questions.js`의 `kind`는 `practice` 또는 `official`로 구분합니다. 실제 기출을 추가할 때는 공식 원문·최종 정답을 직접 대조하고 시험명, 연도, 회차, 문항번호, 원문 URL, 확인일 및 필요한 이용 조건을 기록해야 합니다. 일반적인 공식 사이트 링크만 있다고 기출로 분류하지 않습니다. 기존 ID와 정답을 임의로 바꾸면 과거 기록의 의미가 달라지므로 새로운 ID를 사용하세요.

공식 확인 경로:
- Q-Net 사회복지사 1급: https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=9730
- 행정안전부 2027년 지방공무원 시험 개편: https://www.mois.go.kr/frt/bbs/type010/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000008&nttId=117977
- 국가법령정보센터: https://www.law.go.kr

2027 지방직 한국사는 검정시험 대체 안내에 따라 보충 영역으로 분리합니다. 필기 4과목 통계에는 포함하지 않습니다. 시험일·채용인원·지원 지역별 최종 응시 조건을 이 앱이 확정하지 않습니다.

## 복습 규칙
틀린 시각을 기준으로 24시간 후, 3일 후, 7일 후 복습합니다. 예정일 전 정답은 연습 기록만 남기고 단계는 올리지 않습니다. 기한 도래 후 맞히면 다음 단계로 진행합니다. 늦게 복습한 경우 다음 복습까지 최소 24시간을 보장합니다. 어느 모드에서든 다시 틀리면 그 시각부터 재시작합니다. 3단계 완료 시 오답에서 졸업하고 복습 일정에는 완료 기록이 남습니다. 날짜·연속 학습은 한국 시간 기준입니다.

## 설치·오프라인
Android Chrome에서 앱 주소 열기 → 자료·설정에서 ‘오프라인 학습 준비 완료’ 확인 → 브라우저 메뉴의 ‘앱 설치’ 또는 ‘홈 화면에 추가’.
iOS Safari는 공유 → 홈 화면에 추가. 브라우저에 따라 메뉴·설치 지원이 다릅니다.
기존 앱에서 새 버전이 보이지 않으면 모든 앱 탭과 설치 앱을 닫고 다시 엽니다. 앱 업데이트는 풀이 중 자산이 섞이지 않도록 즉시 강제 활성화하지 않습니다. 사이트 데이터 삭제는 기록도 지우므로 먼저 백업하세요.
Manus의 저장 기록은 다른 출처에 있으므로 자동 이관되지 않습니다.

## 로컬 실행·검증
```sh
python3 -m http.server 8080
# http://localhost:8080 에서 실행 (file://는 PWA 미지원)
node --test tests/*.test.cjs
```

## GitHub Pages
기존 `.github/workflows/deploy-pages.yml`을 유지합니다. Settings → Pages → Source가 GitHub Actions인지 확인합니다.
main 변경 시 Checkout → Node 핵심·오프라인 테스트 → 정적 파일 업로드 → Pages 배포가 실행됩니다. `manifest.webmanifest`의 scope/start_url과 자산 경로는 상대경로여서 프로젝트 하위 경로에서도 실행됩니다.

업로드로 적용하려면 이 저장소 루트 파일들을 같은 이름으로 교체하고 신규 js/css/png를 함께 올립니다. 별도 npm 빌드나 API 키는 필요하지 않습니다.

## 파일
- `index.html`, `styles.css`, `app.js`: 화면과 동작
- `questions.js`: 과목과 문제 데이터
- `core.js`: 채점, 일정, 통계, 백업 검증
- `sw.js`: 동일 출처·현재 앱 범위의 캐시, GET만 처리, 다른 앱 캐시 보존
- `tests/core.test.cjs`, `tests/sw.test.cjs`: 복습 시각·재오답·과목 분리·백업·오프라인 자산 검증
- `VERIFICATION.md`: 실제 검증 결과와 남은 확인 사항

문제를 추가하거나 자산을 변경하면 `sw.js` 및 `app.js`의 캐시 버전 문자열을 함께 올려야 합니다.
